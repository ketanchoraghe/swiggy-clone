
# Swiggy Clone

This project is a frontend clone of the popular food delivery app, Swiggy. It mimics essential functionalities like restaurant browsing, adding food to the cart, and navigating through different food categories. It's built with responsive design principles to provide a smooth experience on mobile, tablet, and desktop devices.

## Features

-Restaurant Listings: Displays a list of restaurants,  including images, names, and ratings.

-Restaurant Menu: Allows users to explore restaurant menus with detailed item descriptions.

-Cart Management: Add or remove items from the cart, with dynamic updates.

-Responsive Design: Ensures compatibility across all screen sizes (mobile, tablet, and desktop).


## Installation

Steps to Run the Project

1.Clone the repository:

git clone https://github.com/ketanchoraghe/swiggy-clone.git
cd swiggy-clone

2.Install the dependencies:

npm install

3Start the development server:

npm start

4.Open the app in your browser:

http://localhost:3000
## Technologies Used
Technologies Used
HTML5 – Semantic structure for content.

CSS3 (Tailwind CSS) – Utility-first CSS framework for styling.

JavaScript – Used for handling dynamic interactions.

React.js – JavaScript library for building the user interface.
## Uses

-Responsive UI: This project features a responsive layout that adapts to different screen sizes, from mobile to desktop.

-Interactive Cart: Users can interact with the cart to add/remove items, and the cart UI dynamically updates to reflect these changes.
